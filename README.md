# Quilio Homebrew tap

Casks for Quilio apps.

## Scribe

Local push-to-talk dictation for macOS. Hold a key, speak, release.
Formerly WhisperGo; `brew upgrade` carries an old install across.

```
brew install --cask godofecht/tap/scribe
```

The app runs free for 14 days. After that, dictation needs a license,
sold at [quilio.dev/scribe](https://quilio.dev/scribe).
